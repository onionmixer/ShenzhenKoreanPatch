* *meter-in*과 *meter-out*은 이 노드를 건물의 스마트 그리드 전력량계에 연결하는 XBus 입력과 출력입니다.
* *lower-in*과 *lower-out*은 이 노드를 ID가 더 낮은 노드에 연결하는 XBus 입력과 출력입니다.
* *higher-in*과 *higher-out*은 이 노드를 ID가 더 높은 노드에 연결하는 XBus 입력과 출력입니다.
* 데이터 패킷의 첫 값은 목적지 ID이며, 이 값에 따라 패킷을 다음과 같이 처리하세요.

##############

| ID < 계량기 ID | 데이터 패킷을 ID가 낮은 노드로 재전송
---------------------------------------------------------------
| ID = 계량기 ID | 데이터 패킷을 계량기로 재전송
---------------------------------------------------------------
| ID > 계량기 ID | 데이터 패킷을 ID가 높은 노드로 재전송

* 현재 노드의 ID는 XBus 입력으로 읽을 수 있는 보안 식별 칩에 저장돼 있습니다.
* 데이터 패킷의 두 번째 값은 패킷의 나머지 부분의 길이입니다.
