* *x*와 *y*는 조이스틱에 연결된 단순 입력입니다.
* *a*와 *b*는 버튼에 연결된 단순 입력입니다.
* *radio-rx*는 무선 수신기에 연결된 비차단 XBus 입력입니다.
* *radio-tx*는 무선 송신기에 연결된 XBus 출력입니다.
* 게임기에서 무선으로 데이터 패킷을 받으면 최신 입력값을 사용해 다음과 같은 값 3개의 데이터 패킷으로 응답하세요.

#############

|     |     | 0, *a* = 0이고 *b* = 0일 때
| *x* | *y* | 1, *a* = 100이고 *b* = 0일 때
|     |     | 2, *a* = 0이고 *b* = 100일 때
|     |     | 3, *a* = 100이고 *b* = 100일 때
